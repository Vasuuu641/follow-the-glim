# Follow the Glim

A voyage-of-discovery game built on OpenStreetMap (theme: Löytöretki).
Follow Glim, a fairy made of light, across a 3D globe and into the map.

## How to run

This project is a static browser app, so you just need to serve the folder over HTTP.

1. Open a terminal in the project folder.
2. Run one of these commands:

```bash
npx serve .
```

or

```bash
python3 -m http.server 8000
```

3. Open the printed local URL in your browser.

## Notes

The game uses live OpenStreetMap services for map tiles, geocoding, and nearby place data. It also includes a local soundtrack file, so running it from a local web server is important.

Map data © OpenStreetMap contributors (ODbL).
Tiles: tile.openstreetmap.org. Data: Overpass API. Search: Nominatim.
Built with MapLibre GL JS. Runs entirely in the browser, with no backend.
